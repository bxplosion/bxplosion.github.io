公式



公式的mdlatex格式：

md内latex公式编写渲染问题很大，有着各种bug，博客采用方案为卸载hexo-renderer-marked，安装hexo-renderer-pandoc（预先安装pandoc），但仍有缺点 - 插入图片方式需要改变 - 加载会慢 - mathjex那样好用的右键菜单没有了 - 书写习惯，单行的$不能后面加空格要直接跟内容
为了不让Nunjucks插件干扰md内latex公式编写有多种解决方案： - Front-matter部分设置disableNunjucks: false - 编写公式不要出现 [[d]]等，改为{ {d} } [ [d] ] 中间空格 经检验，店长的外挂标签hexo-butterfly-tag-plugins-plus在不安装hexo-renderer-kramed而是安装pandoc时，可正常使用

    # 为什么要建立博客

这个博客的主页
建立博客就是个折腾的过程，对于天天看长短视频不操作的云学习人来说，这才是真正体验到理论和实践结合的过程。原本是跟随师兄师姐拿Blog作笔记学习整理一下研究思路等，结果还没发布一篇（除了默认helloworld），就得从github到clone到md到vscode等等工作流都要理顺一遍。特别是主题最折腾，就像是一门只要求及格的课程，总有人为绩点从细枝末节处（格式、字体、报告ppt）展开内卷的状态。
