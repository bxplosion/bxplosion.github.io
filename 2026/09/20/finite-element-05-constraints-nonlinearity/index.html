有限元法（五）：约束、接触思想与 Newton 非线性迭代

bxplosion2026-09-212026-09-20

静力线性问题之所以“好解”，隐含两个前提：可行位移空间已经被正确限定，内力与位移之间是线性关系。约束方法解决第一个前提；Newton 迭代解决第二个前提。本篇把它们放在同一张计算图中。

1. 把边界条件统一写成线性约束

上一章的位移边界只是最常见的约束。更一般地，可写成

\[ \boxed{ \mathbf C\mathbf a=\mathbf d, } \tag{1} \]

其中 \(\mathbf C\) 可以描述指定自由度、多个自由度的线性关系、周期边界、刚性连接或多点约束。

例如两个节点的某个方向需要保持相同位移，可写为

\[ u_i-u_j=0, \qquad \mathbf C= \begin{bmatrix} \cdots&1&\cdots&-1&\cdots \end{bmatrix}. \tag{2} \]

约束不是“附加的小功能”，而是问题定义的一部分。若约束不足，模型有刚体模态；若约束过多或不相容，模型会被锁死、产生虚假反力或根本无解。

2. 四种常用处理方法

2.1 消元法：已知位移的首选

对明确的位移自由度，分块消元最直接：

\[ \mathbf K_{ff}\mathbf a_f = \mathbf f_f-\mathbf K_{fc}\bar{\mathbf a}_c. \tag{3} \]

优点是保持正定性和较好的条件数；缺点是当约束是复杂的线性组合时，重排或构造变换较麻烦。

2.2 拉格朗日乘子法：精确满足约束

令 \(\boldsymbol\lambda\) 为乘子，离散势能的驻值条件得到鞍点系统：

\[ \boxed{ \begin{bmatrix} \mathbf K&\mathbf C^\mathsf T\\ \mathbf C&\mathbf0 \end{bmatrix} \begin{bmatrix} \mathbf a\\ \boldsymbol\lambda \end{bmatrix} = \begin{bmatrix} \mathbf f\\ \mathbf d \end{bmatrix}. } \tag{4} \]

它能在离散层面精确满足 \(\mathbf C\mathbf a=\mathbf d\)，且 \(\boldsymbol\lambda\) 具有约束反力、通量或界面力的物理解释。代价是矩阵变为不定矩阵，求解器与预条件器需要相应调整。

2.3 罚函数法：用很大的刚度逼近约束

构造罚函数

\[ \Pi_\alpha(\mathbf a) = \frac12\mathbf a^\mathsf T\mathbf K\mathbf a -\mathbf a^\mathsf T\mathbf f +\frac{\alpha}{2} \left\|\mathbf C\mathbf a-\mathbf d\right\|^2, \tag{5} \]

驻值方程为

\[ \boxed{ \left(\mathbf K+\alpha\mathbf C^\mathsf T\mathbf C\right)\mathbf a = \mathbf f+\alpha\mathbf C^\mathsf T\mathbf d. } \tag{6} \]

\(\alpha\) 越大，约束误差越小；但条件数往往随 \(\alpha\) 增大而恶化。罚参数不应机械地取“越大越好”，而应按刚度尺度选择，并同时检查约束误差与线性求解误差。

2.4 增广拉格朗日法：精确性与条件数的折中

增广拉格朗日泛函为

\[ \Pi_{\mathrm{AL}}(\mathbf a,\boldsymbol\lambda) = \Pi(\mathbf a) +\boldsymbol\lambda^\mathsf T(\mathbf C\mathbf a-\mathbf d) +\frac{\alpha}{2}\left\|\mathbf C\mathbf a-\mathbf d\right\|^2. \tag{7} \]

常见外层更新为

\[ \boldsymbol\lambda^{(m+1)} = \boldsymbol\lambda^{(m)} +\alpha\left(\mathbf C\mathbf a^{(m+1)}-\mathbf d\right). \tag{8} \]

它避免把 \(\alpha\) 推到极端大，同时逐步恢复乘子法的精确约束能力，是接触、不可压缩性等问题的常用思路。

3. 从等式约束到接触不等式

接触的本质不是“两个面绑在一起”，而是只允许压、不允许穿透。以下把法向接触压力 \(\lambda_n\) 定义为压缩为正；以法向间隙 \(g_n\) 为例，可写成互补条件：

\[ \boxed{ g_n\geq0, \qquad \lambda_n\geq0, \qquad \lambda_ng_n=0. } \tag{9} \]

三条条件分别表示不穿透、无拉力接触和“分离或接触只能二选一”。若软件把法向牵引力定义为拉伸为正，\(\lambda_n\) 的符号会相反，使用前必须核对其约定。接触比等式约束多了活动集切换，因此通常需要活跃集、罚函数、增广拉格朗日或半光滑 Newton 等算法。

接触问题的首要检查量不是彩色云图，而是：

  • 间隙是否为非负；
  • 接触压力是否出现不允许的拉力；
  • 接触反力是否与外载和支座反力平衡；
  • 加载路径改变时接触状态是否合理切换。

4. 非线性从哪里来

离散方程一般写成

\[ \mathbf f_{\mathrm{int}}(\mathbf a,\mathbf q) = \mathbf f_{\mathrm{ext}}(\mathbf a,t). \tag{10} \]

非线性常见来源有：

  • 材料非线性：塑性、超弹性、损伤等使应力不再线性依赖应变；
  • 几何非线性：大位移、大转动使平衡构形和应变度量改变；
  • 边界非线性：接触、摩擦、随动载荷和开闭边界；
  • 外力非线性：外载本身依赖当前构形或位移。

定义残量

\[ \boxed{ \mathbf R(\mathbf a,t) = \mathbf f_{\mathrm{int}}(\mathbf a,\mathbf q) -\mathbf f_{\mathrm{ext}}(\mathbf a,t). } \tag{11} \]

在给定载荷时刻或载荷步内，平衡就是 \(\mathbf R(\mathbf a,t)=\mathbf0\)。

5. Newton–Raphson 迭代

在当前迭代点 \(\mathbf a^{(i)}\) 对残量线性化：

\[ \mathbf R(\mathbf a^{(i)}+\Delta\mathbf a^{(i)},t) \approx \mathbf R(\mathbf a^{(i)},t) +\mathbf K_T(\mathbf a^{(i)},t)\Delta\mathbf a^{(i)}, \tag{12} \]

其中切线刚度是当前载荷时刻的全导数：

\[ \mathbf K_T = \left.\frac{\mathrm d\mathbf R}{\mathrm d\mathbf a}\right|_t = \frac{\mathrm d\mathbf f_{\mathrm{int}}(\mathbf a,\mathbf q(\mathbf a))}{\mathrm d\mathbf a} - \frac{\partial\mathbf f_{\mathrm{ext}}}{\partial\mathbf a}. \tag{13} \]

这里的全导数包含积分点内部变量 \(\mathbf q\) 随本步位移变化的响应；在塑性等问题中，它对应由本构积分返回的一致算法切线。

令线性化后的残量为零，可得 Newton 步：

\[ \boxed{ \mathbf K_T(\mathbf a^{(i)},t)\Delta\mathbf a^{(i)} = -\mathbf R(\mathbf a^{(i)},t), \qquad \mathbf a^{(i+1)} = \mathbf a^{(i)} +\Delta\mathbf a^{(i)}. } \tag{14} \]

若切线正确、初值足够近且解足够光滑，Newton 方法在收敛区间内具有二次收敛。实际有限元计算常在每个载荷步或时间步内执行这个循环。

6. 不收敛时该怎样判断

常用的相对残量指标为

\[ \frac{\|\mathbf R^{(i)}\|_2} {1+\|\mathbf f_{\mathrm{ext}}\|_2} \leq \varepsilon_R. \tag{15} \]

同时还应监测位移增量，例如

\[ \frac{\|\Delta\mathbf a^{(i)}\|_2} {1+\|\mathbf a^{(i+1)}\|_2} \leq \varepsilon_a. \tag{16} \]

只看其中一个指标可能误判：残量小但位移仍在漂移，或增量小但残量远未平衡，都不应被当作可靠收敛。

若迭代发散或振荡，按以下顺序排查通常更有效：

  1. 确认荷载步是否过大，并减小增量；
  2. 检查约束、接触状态、材料参数和单位；
  3. 检查内变量是否在每个 Gauss 点正确更新；
  4. 使用一致切线，而非长期沿用初始刚度；
  5. 需要时加入线搜索、弧长法或自动步长控制。

把“迭代次数增加”当作第一反应，往往只是更久地计算一个定义有问题的模型。

小结

约束决定可行空间，残量决定平衡状态，切线刚度决定局部修正方向：

\[ \mathbf C\mathbf a=\mathbf d, \qquad \mathbf R(\mathbf a,t)=\mathbf0, \qquad \mathbf K_T\Delta\mathbf a=-\mathbf R. \]

下一篇补上结果可信度的最后几层：误差估计、稀疏矩阵、迭代求解器与塑性本构积分。
