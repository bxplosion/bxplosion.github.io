有限元法（六）：误差估计、稀疏矩阵、求解器与塑性入门

bxplosion2026-09-212026-09-20

有限元不是“把连续问题离散后交给求解器”就结束。离散误差、代数误差、材料积分误差和后处理误差会叠加在一起。本篇把误差理论、稀疏求解与塑性放在同一框架下，回答一个更工程化的问题：怎样知道结果可信到什么程度。

1. 有限元误差来自哪里

设连续弱形式为：求 \(u\in V\)，使

\[ a(u,v)=\ell(v)\qquad\forall v\in V_0. \tag{1} \]

有限元解 \(u_h\in V_h\subset V\) 满足

\[ a(u_h,v_h)=\ell(v_h)\qquad\forall v_h\in V_{h,0}. \tag{2} \]

若 \(e=u-u_h\)，则有 Galerkin 正交性

\[ \boxed{ a(e,v_h)=0 \qquad\forall v_h\in V_{h,0}. } \tag{3} \]

对于对称、连续、强制的双线性形式，定义能量范数

\[ \|w\|_a=\sqrt{a(w,w)}. \tag{4} \]

则有限元解具有最佳逼近性质：

\[ \boxed{ \|u-u_h\|_a \leq \|u-v_h\|_a \qquad\forall v_h\in V_h. } \tag{5} \]

它的意思不是“任何网格都准确”，而是：在已经选定的有限维空间 \(V_h\) 中，Galerkin 解至少不比任意其他候选函数差。

2. 网格尺寸、阶次与解的光滑性

若单元多项式阶次为 \(p\)，精确解具有 \(H^r\) 正则性，常见先验估计可写为

\[ \boxed{ \|u-u_h\|_{H^m(\Omega)} \leq C h^{\min(p+1-m,\ r-m)} \|u\|_{H^r(\Omega)}. } \tag{6} \]

这里 \(h\) 是特征单元尺寸，\(m=0\) 对应 \(L^2\) 型误差，\(m=1\) 对应 \(H^1\) 或能量型误差。它揭示三件事：

  • 细化网格（\(h\) 减小）通常降低误差；
  • 升高单元阶次（\(p\) 增大）可提高收敛速度；
  • 若真实解在裂纹尖端、再入角或材料界面附近不够光滑，理论最优阶会下降。

因此，面对奇异点，单纯全局加密往往代价高。更合理的选择是局部 \(h\) 自适应、局部 \(p\) 提升，或二者组合的 \(hp\) 自适应。

3. 从先验理论到工程验证

先验估计依赖未知的精确解，工程中更常做以下验证：

  1. Patch test：线性单元能否精确再现线性位移场或常应变场；
  2. 网格收敛：比较关心的位移、反力、能量释放率或平均应力，而非只比较单点峰值；
  3. 时间步收敛：瞬态问题减小 \(\Delta t\) 后，关键峰值和相位是否稳定；
  4. 平衡检查：外力、约束反力、接触力和惯性项是否闭合；
  5. 基准算例：与解析解、制造解、实验或可信高精度解比较。

若某个目标量随网格持续单调漂移，应报告它尚未收敛，而不是从最后一张云图中挑一个看起来顺眼的数字。

4. 为什么总体矩阵是稀疏的

单元形函数只有局部支撑。若两个自由度对应的形函数支撑集不相交，则它们之间没有单元积分耦合：

\[ \operatorname{supp}N_i\cap\operatorname{supp}N_j=\varnothing \quad\Longrightarrow\quad K_{ij}=0. \tag{7} \]

共同出现在一个单元中是 \(K_{ij}\) 可能非零的必要条件，但在特殊材料、几何或积分规则下该项也可能恰好为零。稀疏性来自物理局部性，而不是一种可有可无的编程优化。大规模有限元必须使用 CSR、CSC 或块稀疏存储，避免把大量零元素当成数据保存和运算。

对施加了足够位移约束的线弹性问题，\(\mathbf K\) 通常为对称正定矩阵。其谱条件数为

\[ \kappa_2(\mathbf K) = \frac{\lambda_{\max}(\mathbf K)} {\lambda_{\min}(\mathbf K)}. \tag{8} \]

网格高度畸变、材料参数跨越极大数量级、近不可压缩性、过大的罚参数和未完全消除的刚体模态，都可能使 \(\kappa_2\) 变大，从而放大舍入误差并拖慢迭代求解。

5. 直接法、迭代法与预条件

没有一种求解器对所有问题都最好。

  • 直接法：如稀疏 Cholesky、LU，鲁棒且适合中等规模或多右端问题，但填充和内存可能昂贵；
  • 共轭梯度法：适用于对称正定系统，例如约束处理后的线弹性刚度方程；
  • GMRES 等 Krylov 方法：适用于一般非对称或不定系统，例如某些流固耦合、乘子约束与非对称切线；
  • 多重网格与领域分解：面向大规模问题，通过多尺度或子域结构降低迭代成本。

预条件器 \(\mathbf P\) 的目标不是精确等于 \(\mathbf K\)，而是以低代价近似其主要谱特性，使

\[ \mathbf P^{-1}\mathbf K\mathbf a = \mathbf P^{-1}\mathbf f \tag{9} \]

更容易迭代。好的预条件通常比“把迭代次数上限调大”更有价值。

6. 塑性：内变量让材料具有历史

线弹性中 \(\boldsymbol\sigma=\mathbb C:\boldsymbol\varepsilon\) 与加载路径无关。塑性中，需要把总应变分解为

\[ \boldsymbol\varepsilon = \boldsymbol\varepsilon^e+\boldsymbol\varepsilon^p, \qquad \boldsymbol\sigma = \mathbb C: \left(\boldsymbol\varepsilon-\boldsymbol\varepsilon^p\right). \tag{10} \]

对各向同性 J2 塑性，偏应力与等效应力为

\[ \mathbf s=\operatorname{dev}\boldsymbol\sigma, \qquad \sigma_{\mathrm{eq}} = \sqrt{\frac32\mathbf s:\mathbf s}. \tag{11} \]

一个带线性各向同性硬化的屈服函数可写为

\[ \boxed{ f(\boldsymbol\sigma,\kappa) = \sigma_{\mathrm{eq}} -\left(\sigma_{y0}+H\kappa\right) \leq0, } \tag{12} \]

其中 \(\kappa\) 是累积等效塑性应变，\(H=0\) 对应理想塑性。关联流动法的 Kuhn–Tucker 条件为

\[ \dot{\boldsymbol\varepsilon}^p = \dot\gamma\frac{\partial f}{\partial\boldsymbol\sigma}, \qquad \dot\kappa=\dot\gamma, \qquad \dot\gamma\geq0, \qquad f\leq0, \qquad \dot\gamma f=0. \tag{13} \]

它表达了弹性加载、屈服面加载与卸载的切换逻辑。

7. Gauss 点 return mapping 与一致切线

塑性状态不应只储存在节点上，而通常储存在每个积分点。一个典型增量算法是：

  1. 假设本步完全弹性，构造试应力 \(\boldsymbol\sigma_{\mathrm{tr}}\)；
  2. 计算 \(f_{\mathrm{tr}}\)；
  3. 若 \(f_{\mathrm{tr}}\leq0\)，接受弹性状态；
  4. 若 \(f_{\mathrm{tr}}>0\)，将试应力返回屈服面，更新 \(\boldsymbol\varepsilon^p\)、\(\kappa\) 与应力；
  5. 返回一致算法切线 \(\mathbf D_{\mathrm{alg}}\)，供总体 Newton 迭代组装。

关键在最后一步。若只更新应力而返回不一致的切线，整体 Newton 迭代会明显变慢，甚至在强塑性阶段不收敛。于是材料积分、单元积分和总体 Newton 形成嵌套结构：

\[ \text{Gauss 点本构更新} \Longrightarrow \mathbf f_{\mathrm{int}},\ \mathbf K_T \Longrightarrow \text{总体 Newton 平衡}. \tag{14} \]

8. 一份最小可信度清单

完成一次有限元计算前，建议至少留下以下证据：

  • 模型图：材料、单位、荷载、边界和坐标系清晰；
  • 数值设置：单元类型、积分规则、网格尺度、时间步与求解器容差可复现；
  • 约束与平衡：反力、接触力或惯性项的闭合检查；
  • 收敛图：目标量随网格或时间步的变化；
  • 物理解释：说明峰值是否受奇异性、后处理或网格影响；
  • 若含塑性：报告内部变量、屈服区与加载路径，而不只展示应力云图。

小结

有限元的可靠性不是由一处开关决定的，而是下面几层共同作用：

\[ \text{逼近空间} \rightarrow \text{网格与积分} \rightarrow \text{稀疏线性代数} \rightarrow \text{本构更新} \rightarrow \text{平衡与收敛验证}. \]

至此，课程的主线已经闭合：从连续体的弱形式出发，经过单元离散和求解，最后回到可量化的误差与物理验证。后续无论学习 FEniCS、商业有限元软件还是自行编写程序，都可以用这条链检查每一个设置是否有明确的数学和力学来源。
